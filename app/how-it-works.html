The POC · hackathon build

A call that works today

What we built for the Meta Global AI Developer Hackathon: real telephony on an ordinary feature phone / basic phone — not a browser or WhatsApp-required demo. Works on ordinary phone (no app required). WhatsApp option for those who have it, but not required.

Open /dashboard during a call to see live latency breakdown. Backup demo ↗

Call path · feature phone / basic phone

1 · CallerFeature phone / basic phone / ordinary phone dials Exotel number (ordinary call — WhatsApp not required, not WebRTC)
2 · TelephonyExotel POTS → Windows Server. Location asked today; tower triangulation later with operator tie-ups.
3 · STTMeta Voice Transcribe — Hindi/English + language ID
4 · ReasonMuse Spark — short 2–3 sentence answers; follow-up only if needed
5 · SpeakMeta TTS + waiting tone · keypad 1 capabilities · 2 English · 3 Hindi · 9 interrupt
